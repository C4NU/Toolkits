# Lightroom Backup

사진 파일의 EXIF 데이터를 읽어 촬영 날짜(`YYYY_MM_DD`) 기준으로 폴더를 생성하고 자동으로 분류해 주는 쉘 스크립트(`sort_photos_by_exif.sh`)입니다. 라이트룸(Lightroom) 등의 사진 편집 전후로 원본 파일과 보정 데이터(XMP)를 흩어지지 않게 함께 관리하고 정리할 때 유용하게 사용할 수 있습니다.

## 주요 기능

- **사진 날짜별 분류**: 사진의 EXIF 정보 중 `DateTimeOriginal` 속성을 추출하여 해당 날짜 이름의 폴더(예: `2023_10_25`)를 만들고 파일을 정리합니다.
- **다양한 포맷 지원**: 기본 이미지 파일(JPG, JPEG, PNG, HEIC, GIF, TIF, TIFF)뿐만 아니라 RAW 포맷(ORF, ORI 등)을 인식하여 처리합니다.
- **동기화된 XMP 파일 이동**: 사진 파일과 동일한 이름의 XMP 사이드카 파일(`.xmp`, `.XMP`)이 같은 폴더에 존재할 경우, 사진과 떨어지지 않도록 함께 타겟 폴더로 이동시킵니다.
- **예외 처리 내장**: EXIF 메타데이터에 날짜 정보가 누락된 경우, OS 파일 시스템의 생성 일자를 대신 사용합니다. 그마저도 판단할 수 없으면 `unknown_date` 폴더로 안전하게 분류합니다.

## 사전 요구 사항

파일의 EXIF 데이터를 빠르고 정확하게 추출하기 위해 내부적으로 `exiftool`을 사용합니다. 스크립트 실행 전 시스템에 설치되어 있어야 합니다.
(macOS에서는 Homebrew를 통해 쉽게 설치 가능합니다.)

```bash
brew install exiftool
```

## 사용법

터미널을 열고 스크립트를 실행합니다. 원본 파일이 있는 폴더와 분류된 파일들이 저장될 폴더를 지정할 수 있습니다.

```bash
./sort_photos_by_exif.sh [원본_폴더_경로] [결과_폴더_경로]
```

### 인자(Argument) 생략 시 기본 동작
명령어 뒤에 경로를 명시하지 않고 바로 실행하면 다음과 같이 기본값이 적용됩니다.
- **원본 폴더**: 현재 터미널이 위치한 디렉토리 (`.`)
- **결과 폴더**: 원본 폴더 하위에 생성되는 `sorted_by_date` 디렉토리

```bash
# 현재 폴더의 사진들을 정리하여 현재 폴더 내 sorted_by_date 에 모으기
./sort_photos_by_exif.sh
```

## 주의 사항
- 스크립트는 원본 파일을 복사(copy)하는 것이 아니라 **이동(move)** 처리합니다. 필요한 경우 실행 전에 데이터가 안전하게 보관되어 있는지 확인하시기 바랍니다.
- 결과 폴더 내부 경로를 스캔할 경우 중복 처리를 방지하기 위해 해당 경로는 제외됩니다.
